# gsc-cli Docs

Project documentation for the standalone read-only Google Search Console CLI.

## Contents

- `guides/`
  - operator-facing usage guides

## Current Operator Entry Points

- `gsc-cli doctor`
- `gsc-cli help <topic>`
- `gsc-cli analytics top-pages`
- `gsc-cli analytics top-queries`
- `gsc-cli report overview`
- `gsc-cli report compare`
- `gsc-cli version`

## Installation

System-wide install target:

- `$(brew --prefix)/bin/gsc-cli`
